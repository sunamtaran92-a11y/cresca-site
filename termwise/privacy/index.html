Termwise privacy policy

Local review and Google Ads

CSV review, rule-based analysis and report decisions run locally. Connecting Google Ads uses Chrome Identity for authorization and sends reporting requests with your Google access token to googleads.googleapis.com. Termwise retrieves accessible account metadata, search-query metrics, keyword coverage, applicable negatives and, with Pro, keyword and landing-page performance. It reads no unrelated browser pages. Pro users can explicitly review, validate and confirm supported exact-keyword changes in their Google Ads account.

Google account selection uses a Google-hosted account chooser, authorization code and PKCE. The Termwise Cloudflare service transiently exchanges the code with Google and returns the access token to the extension. It does not retain codes or tokens, request offline refresh access, or send tokens to its AI model. Access tokens remain in trusted extension session storage for up to one hour, until disconnect or browser close. Tokens never enter report exports, local license storage or quota records. Accessible account metadata is stored in Chrome session storage until disconnect or browser close. Reports and review decisions remain in page memory unless you export a local file. Pro client briefs and the license key persist in extension local storage until removed or the extension is uninstalled.

Optional landing-page context

Without a client brief, Termwise uses loaded conversion history, enabled keywords and existing exclusions as tentative business context. Choosing Use landing-page content asks Chrome for optional access only to the selected HTTPS website origins. The extension reads up to three landing-page URLs drawn from the loaded report or your website field, without cookies or stored browser credentials. Tracking query strings and fragments are removed; redirects are not followed. Each page has a size and time limit. Page titles, headings and short text excerpts are held in workspace memory, are not executed, and are discarded when the workspace closes. Pages are filtered to the URLs associated with the current report before use. Chrome manages the optional website permission; you can revoke it in extension settings. The website receives the request and ordinary connection metadata.

On-device analysis can use these page excerpts and account-history examples locally. If you separately consent to Pro cloud analysis, a bounded summary of page content and inferred account context is included with the batch, metrics and brief sent to Termwise and Cloudflare. Do not grant page access or cloud consent for confidential website material you do not want processed. A missing brief or unavailable page does not block account-history analysis. Inferred context is not a verified business policy and never triggers an advertising change.

Free cloud trial and integrated AI

AI controls and findings appear inside workspace sections. Cloud analysis requires the displayed data-sharing consent. Selected evidence may include search queries, keyword metrics, phrase examples, campaign comparisons, negative-scope findings, page excerpts and aggregate reported-query campaign totals. Complete reports and Google tokens are not sent to the model. The data is limited to the selected batch and bounded context. AI results remain in workspace memory unless exported; report-session saves omit AI results.

The first 20 cloud AI items per installation may be tried without a Pro license. The extension creates a random anonymous installation ID in local storage and sends it to Termwise for trial enforcement. Termwise stores a SHA-256 digest and a lifetime usage count in its quota database. Trial records do not reset with monthly counters. Clearing findings or a report does not restore trial allowance. Failed model attempts return trial items but still count against shared daily capacity. Request-rate limiting uses short-lived hashed-IP counters. Pro verification and monthly usage remain as described below. This is an installation-level trial, not verified identity. Contact the operator about quota-record deletion.

On-device AI is a Pro alternative; Google controls model availability and downloads. Local AI does not send its batch to the cloud service. A local failure never automatically sends data to cloud AI.

Optional on-device AI

Choosing Analyze on this device uses Chrome's built-in language model where supported. Chrome may download a model first. The query batch, metrics and business context used for this mode are processed on your computer. This mode does not send them to the Termwise cloud service. AI results are suggestions; they do not change advertising accounts or replace approved decisions. Results are retained in tab memory and can be exported as a local AI-review CSV.

Optional Pro cloud AI

Cloud analysis uses either the installation trial or a verified Pro license and requires acceptance of its workspace data notice. Termwise sends up to 20 query strings, their selected cost/click/conversion metrics, protection flags and the relevant business brief to the operator's Cloudflare Worker. The brief includes service, brand and exclusion phrases, client instructions, target CPA and currency. Termwise does not send Google access tokens, complete Google account reports, payment-card details or account identifiers in this analysis request.

The Worker sends the batch to Cloudflare Workers AI for inference. The configured model is Cloudflare-hosted Qwen 3.8 27B, documented by Cloudflare as zero data retention. Cloudflare processes requests and service/security metadata under its own terms. Termwise does not enable request-body logging or an analytics service. Query text, prompts and model outputs are not written to the Termwise quota database.

Your Pro license key is sent securely to the Worker and to Gumroad for active-membership verification. The Worker stores a SHA-256 digest of the license and usage counts to enforce the monthly allowance, plus short-lived hashed-IP request counters and shared daily usage. These are operational quota records, not report storage. The ledger resets the relevant counters on subsequent requests in a new period; records may remain while the service is inactive. Contact the operator about quota-record deletion. Neither Google access tokens nor raw license keys are stored in this ledger.

Cloud AI is optional. You can continue using local rule review without sending report data to the operator's cloud service. Do not include personal information or secrets in query text or business instructions you choose to send. The extension displays model output as text and treats suggestions as unverified review guidance.

Licenses and purchases

License activation sends your license key and the public Pro product ID to api.gumroad.com. Gumroad verifies purchase, refund, dispute and membership status. The extension stores your key locally for future checks but does not retain your card data or the full billing response. Checkout opens the configured Gumroad product page. Gumroad handles payments, receipts and buyer information under its own policies.

Optional Pro write-back to Google Ads

The extension can create campaign-level exact negative keywords and paused ad-group exact keywords only after explicit user review and confirmation. It first retrieves current 90-day report/keyword data, resolves stable resource IDs, checks conversion and keyword protections, and sends Google a validate-only request. The review shows the customer, MCC route, campaign/ad-group IDs, actions and keyword status. Confirming applies that fixed batch to the selected account using the existing Google Ads authorization. No budget changes, campaign activation or arbitrary recommendation execution are exposed.

Prepared batches are held in trusted extension session storage for at most five minutes, bounded to five reviews and 50 actions per batch. A review ticket is consumed and persisted before any write. The extension rechecks protections and validates again before submitting an atomic request with partial failure disabled. An ambiguous response does not trigger an automatic retry. Changes may already have occurred after a network failure; the user must check Google Ads before preparing another batch. Google Ads permissions and API approval must allow edits.

Confirmed execution records, including account/MCC IDs, item details, resulting resource names and timestamps, are saved locally on the device, capped at the latest 100 batches, and can be downloaded from the confirmation. They are not sent to Termwise or Cloudflare. No Google access token enters these records. Browser storage removal or uninstalling removes these local records; Google retains its own account change history. Clearing workspace reports does not remove execution history. Writes may affect ad traffic; a negative is active when applied. Newly created positive keywords are paused and require separate activation in Google Ads.

Your controls

Clear workspace resets the current report; Clear AI results clears the AI suggestions held in the tab. Closing the workspace clears unsaved report and AI data. Disconnect clears the extension's Google token/account caches. Remove license deletes the local license key. Uninstalling removes extension storage, including saved briefs; it does not delete previously downloaded files. You can delete local exports yourself. The operator cannot remotely retrieve or delete data that exists only on your device.

Limited use

Termwise uses Google user data only for the reporting and review features you request. It does not sell that data, use it for advertisements or train AI models with it. Termwise's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Optional AI transfers are limited to the user-facing analysis described above.

Termwise has no advertising pixels or unrelated browsing analytics. Samples are fictional. Changes to data handling will be reflected in an updated policy with a revised effective date.
