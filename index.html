The Google Ads API tool

A private tool, built for this practice

I built and operate a tool on the Google Ads API to support the account work above. It is a Model Context Protocol (MCP) server that connects the API to Claude, so the accounts I manage can be queried, analysed and changed conversationally instead of assembled by hand.

It is written in Python on Google's official google-ads client library (31.1.0, API v24), and authenticates as me over OAuth 2.0. The source is public: github.com/sunamtaran92-a11y/google-ads-api-tools

Operated solely by me, for my clients. I am the only person who operates the tool. It manages the Google Ads accounts of my clients, who are external parties, linked under my manager account 624-846-9807. Clients do not log into it, it is not sold, licensed or offered for sign-up, and it has no public interface. It reads and changes only accounts I already hold access to.

What it does

19 tools across 8 API services. Nine read, eight stage a change, one applies a staged change, one lists what is staged.

CapabilityWhat it covers
ReportingCampaign performance, budget pacing, ad disapprovals, search terms, and arbitrary GAQL — SELECT statements only.
Keyword planningKeyword ideas, historical search volume and competition, and click / cost / conversion forecasts.
Campaign managementCampaign and keyword status, daily budgets, campaign-level negative keywords.
Campaign creationSearch campaigns — budget, campaign, ad group and keywords. Created paused, with no ads, so nothing serves until it is reviewed.
Account creationNew client accounts under the manager account.
Account managementAccount name and auto-tagging settings.

Every write is gated

Nothing in the tool changes an account directly. A propose_* tool validates the request, builds a plan, and returns it with a single-use confirmation token — writing nothing. Only apply_change mutates, and only for a plan a propose_* staged. Tokens expire after ten minutes and cannot be replayed.

An LLM proposing a change is useful. An LLM applying one to a live client account unreviewed is a different risk class. So a human sees every plan before it executes.
